# GÖRSEL VE SES KAYNAKLARI / TELİF BİLGİSİ

Bu oyunda kullanılan dış kaynaklı materyallerin tamamı **kamu malı (public
domain)** veya **serbest lisanslıdır**. Sınıf içi kullanım için ek izin
gerekmez; aşağıdaki atıflar kayıt amaçlıdır.

## Hücre zarı — `assets/membrane/`

`bilayer_tile.png`, projede zaten bulunan `membrane_tile.png` dosyasından
türetilmiştir (tek fosfolipid periyodu kırpılıp yatayda kusursuz tekrar
edecek şekilde ayarlandı). Orijinal dosyalar korunmuştur.

## Kanal / mekanizma görselleri

`assets/channels/` içindeki iki görsel **oyunda kullanılmamaktadır** (bkz.
README bölüm 0). Altı mekanizmanın kanal görseli oyun içinde canvas ile
çizilir; hiçbir dış kaynak kullanılmaz.
